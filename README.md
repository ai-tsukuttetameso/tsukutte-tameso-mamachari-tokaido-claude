# ママチャリ東海道（Claude版）

YouTube「AIでつくってためそ」第6回のために、AI（Claude）が作ったブラウザで遊べる自転車の横スクロールゲームです。

▶ **遊ぶ：** https://ai-tsukuttetameso.github.io/tsukutte-tameso-mamachari-tokaido-claude/

## あそびかた

- スタート画面で「やさしい／ふつう／むずかしい」を選びます
- タップ／クリック／スペースキー（↑キー）でジャンプ、空中でもう一回押すと2段ジャンプ
- 谷に落ちる、壁に正面からぶつかるとゲームオーバー。走るほどスピードが上がります

## できること

- **距離を地名に換算**：名古屋をスタートして東海道を東へ。「名古屋から○km」「次の地名まであと○km」を表示（ゲーム内1m＝実際の100m）
- **ご当地背景**：名古屋城、豊橋の路面電車、浜名湖、浜松、静岡の茶畑、富士山、箱根の温泉、横浜の観覧車、東京のタワー…と景色が流れ、東京の先は青森まで続きます
- **時間帯の移り変わり**：朝9時に出発し、走るほど夕方・夜へ。夜は自転車のライトが照らす範囲しか見えにくくなります
- **ゴースト並走**：コースは毎回同じ。ベスト記録の走りが半透明で一緒に走り、ベスト地点には旗が立ちます
- **回転ジャンプ**：崖や壁のギリギリで踏み切ると1回転、さらにギリギリなら2回転。決めて着地するとコンボ
- **難易度選択**：スピード・谷の広さ・壁の高さ・ギリギリ判定が変わります。ベスト記録とゴーストは難易度ごとに保存
- ゲームオーバー演出は控えめ。結果画面で走行距離・たどり着いた地名・最大コンボを表示
- スマホ対応
